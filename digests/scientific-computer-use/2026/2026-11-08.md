## 1. Goal-Driven Autonomous Optical Experimentation via a Self-Recursive Hardware-Software Harness

[原始来源](https://arxiv.org/abs/2611.04481)｜2026-11-03；版本见来源。

透视式增强现实眼镜发出的光会与背景光叠加。同一个RGB指令换个背景就可能呈现另一种颜色，因此研究者需要测实际光谱、建立响应关系，再选择显示参数逼近目标颜色。本文把问题扩大到实验环境本身：如果软件不能稳定显示模型算出的颜色，或者采光时不知道设备实际处于什么状态，再聪明的参数优化也无法形成可信证据。

作者用iPad产生背景、RayNeo X3眼镜发光，TOP 300探头接CAS140D光谱辐射计采集真实光谱。控制依赖专门开发的应用及HTTP、USB/ADB和仪器SDK；不是截图点击现成软件。论文分配了科学规划、设备应用开发、测量应用开发和进展监测职责。关键的实际修订是给眼镜应用增加任意RGB的HOLD指令，使颜色在曝光期间保持不变，并回传指令标识、会话和绘制确认；主机把这些回读与光谱共同保存。这样一次“颜色测量”才同时包含刺激条件、设备确认和观测。正文关于未来时序研究的例子只是可能扩展，不是已经完成的实验。

真实证据包括接口修订、参数反馈和模型更新三层。新版接口通过12项现场控制检查；这证明控制通路可用，不是12项科研任务全部成功。一个固定目标经过两次反馈调整，CIELAB色差从19.756经5.315降至1.211；色差越小代表在指定色度系统里越接近目标，不能直接解释为所有观看条件下人的感受相同。独立五目标比较全部改善。进一步，作者按整组目标颜色留出数据比较响应模型，再对新旧模型各自生成的设置取得新光谱：三个目标乘三个背景共九组成对测试，新模型七组更好、两组更差。这个结果比单次漂亮轨迹更有价值，也限制了“模型修订普遍有益”的说法。

建议先读§6.2—6.4和图5，看清接口修订、参数反馈、响应模型修订分别由哪些证据支持。


## 2. Comparing Computer Use Behavior Across Multiple Levels of Abstraction

[原始来源](https://arxiv.org/abs/2610.26703)｜2026-10-19；版本见来源。

比较两套计算机代理时，鼠标点击数往往没有同一种含义：一种界面需要导航和找控件，另一种可能一条命令就完成相同目的。只比较最终成功率又会隐藏恢复、求助和验证过程。本文要解决的是怎样把不同人的、不同接口的操作轨迹转换为可以对应的行为描述，而不是训练一个更强代理。

MAP把轨迹分成相互关联的抽象层：底层是具体操作，向上描述界面目标和操作后果、局部完成方法，最后归到任务目标。通过语义标注管线，把不同输入方式的轨迹映射到共同词汇，再比较次序、重复模式和工作量。这样同样是检索资料，键盘逐项导航与鼠标定位虽然在底层不同，可能仍属于同一种方法；反过来，同样达到目标的两条轨迹也可能在额外验证和清理窗口上不同。这是对既有电脑使用记录的分析，没有仪器、没有新的科学测量，也不把用户界面层的相似度当科学正确性。

作者在三个计算机使用数据集上评估，人工对照部分有28条轨迹。按轨迹平均，直接界面目标的精确匹配率为81.8%，方法标签为79.5%；后者的标准差28.8说明不同轨迹差异很大。对136个抽查的第三层错误，绝大部分涉及把连续动作划成几段的分歧，而非同一边界下认错方法。因此，标注一致性有依据，但生成的分段不能直接当事实。另一个容易误读的数字是词汇覆盖率：能找到适用标签，并不等于自动标注正确。人和代理轨迹的分析显示，高层主目标相近可以与低层行为明显不同同时成立；一些代理遗漏求助等辅助目标，但不能概括成代理从不验证，正文也报告某代理验证更多。

建议先读§3—5及表5—6，区分标注精度、词汇覆盖和行为差异三种证据。


## 3. Silent Instrument Errors Reorder Agent Leaderboards

[原始来源](https://arxiv.org/abs/2611.04399)｜2026-11-03；版本见来源。

这里的“仪器”指评分、计费、日志和重放管线，不是实验室硬件。作者问的是：排行榜上一套通用代理比任务专用框架差，究竟是代理能力差，还是两者根本没有被同样测量？研究仅审计HAL与tau2-bench公开记录和代码，没有重跑代理，也没有调用模型，因此可以较清楚地把结果变化定位到测量过程。

最有信息量的案例是终止方式。专用框架正常触发结束评分，而通用代理自行结束后，模拟用户往往没有发出评分所需的停止信号。后者只有约51%的回合真正被评分，其余存为失败；专用框架约98%。作者从原始日志中分开代理和评分器动作，固定环境后补评。九个共同模型、涉及数据库操作的41个任务口径下，通用代理汇总准确率从0.30到0.43，与另一框架原来的13个百分点差距合拢。这个结果支持“原差距包含漏评”，不支持“通用代理已经全面优于专用框架”：两者步数预算和获取政策文件的方式仍不同，纯读取任务也可能在不改数据库时通过；真正需要写入的子集只从0.28升到0.33。

另外三类问题解释了为什么只有合理数字还不够。嵌套调用同时记录父子日志后，相同模型响应可能被计费两次，而且不是每条路径都翻倍，成本前沿因此会变形。评分器重放标准动作时又写进同一动作列表，2334条航空记录中约68%含这类污染，下载轨迹的人可能误把标准答案当代理行为。最后，更新评分器或错误识别旧文件的运行模式，会改变原有轨迹得分；这不是模型取得新能力。论文记载HAL维护者确认三项问题，但该确认只按作者报告引用，本轮没有独立复算其公开归档。

建议先读§3.2—3.4和表1，关注补评怎样改变差距，以及修正后仍不相同的比较条件。


## 4. Tiny Observatory for Telescope Optimization (TOTO): testing algorithms for autonomous on-orbit alignment for space-based telescope systems

[原始来源](https://arxiv.org/abs/2607.27457)｜2026-07-29；版本见来源。

望远镜获得清晰图像之前，需要把镜面位置和波前误差校准好。太空设备若能主动校正，对地面被动对准和验证的依赖可能降低。本文提供的是地面光学台上的初步实测：此前模拟里可行的自动对准算法，面对真实运动回差、噪声和机械约束，还能做到什么。该工作也提供不依赖语言模型的物理反馈基线。

TOTO用可移动次镜和变形镜模拟对准问题，以单色光源代表轴上点光源。先用Zemax模型和台架实测了解次镜各方向移动对光斑的影响，再由随机并行梯度下降做粗调：扰动可控方向，观察光斑尺寸变化，迭代减少误差。进入适合精调的状态后，焦点多样性相位恢复对同一系统施加不同离焦量，利用多张图像反求波前，再控制变形镜。这里新图像确实参与下一轮控制，决策者是预设数值算法；不是LLM推理、截图GUI操作或远程用户科研。

物理条件非常具体。一条倾斜轴因机械问题无法使用，所以联合粗调测试只包含三个平移方向和另一旋转方向；模拟的无噪声理想系统不能直接给出台架增益。作者按敏感度选20微米均方根光斑尺寸作为粗调停止阈值，达到后继续观测稳定性。相位恢复每轮使用四个离焦量，闭环通常运行十轮，即使三至五轮已看见合理收敛。论文展示了粗调前后光斑、收敛轨迹及粗调后剩余相位误差的恢复。结论仍将更完整自由度、宽带光源和偏轴条件留给后续，不能把这些初步结果写成已在轨、所有条件都达到衍射极限。

建议先读§2.2、§4及图4—9，核对算法切换依据、故障轴和实际展示的收敛范围。


## 5. Measuring the collaboration, not the agent

[原始来源](https://arxiv.org/abs/2611.06487)｜2026-11-04；版本见来源。

科学软件里哪些变量有意义，经常只有现场专家知道。仅让代理独立完成任务再与标准答案比较，会漏掉专家接受、否决和修正建议的作用。本文提出衡量这种协作的办法：代理先提议一个视图，分析者接受、拒绝或调整，并把这些判断留到后续会话。重点是评价能否测出来，不是证明真实科学家用了代理一定更好。

实验用公开半导体制造数据SECOM设计平行坐标视图，即把多个变量排成平行轴以观察数据关系。建议器按不使用标签的结构特征选变量和布局；主实验采用规则启发式，并不是数千次LLM实验。模拟分析者具有预先设定的专业知识、信任和探索倾向。日志保存谁提出、接受、重排或删除了什么，以计算协作互补性、干预效率、依赖是否合适和知识保持等指标。第五项人的自主性尚未验证。没有真人参与，没有本轮器件测量，历史制造数据的分析也没有反向控制生产过程。

作者用4980个模拟会话检验这些量能否响应已知条件。在相同参数格内，协作仅在34.7%的格子优于双方单独做，主要出现在模拟专家知识较少的条件；知识达到较高水平时，独立专家反而更好。这个比例不是用户成功率，更不能当科研效率提升。保留接受和拒绝历史时，五次会话达到预定损失阈值所需干预从2.18降到0.70；不保留历史的对照没有同样下降。该对照必要，因为后续数据块本来就可能更容易。改变评价权重还能改变协作胜负，显示“质量”定义本身影响结论。小规模LLM替换只覆盖三个参数格、五个随机种子，不能承担主实验规模的证明力。

建议先读§4.3—5及图2，确认模拟专家、记忆消融和评价权重怎样共同影响“协作更好”。
