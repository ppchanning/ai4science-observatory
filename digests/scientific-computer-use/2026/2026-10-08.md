## 1. ScienceClaw: Benchmarking Continual Self-Evolution of AI-for-Science Agents Across the Natural and Social Sciences

2026-10-06｜arXiv预印本 v1｜水位增量新工作｜Mingda Zhang、Wenjin Liu、Erik Cambria等。
[原始页面](https://arxiv.org/abs/2610.08691)；[正文／原文1](https://arxiv.org/html/2610.08691v1)。

问题与方法：固定模型参数，把失败—修复轨迹转为相连的Skill与Operator；原任务重放和独立科学任务验证均通过后才接受更新。
应用与控制：代码、数据与结构化科学工具；多轮执行，不是科学软件GUI控制。
硬件／数据与反馈：计算任务与既有数据；未展示新物理实验。只取工程、地球等非生物任务作为项目线索。 执行反馈改变后续工具行动及技能；不等于新实测改变仪器计划。
已核结果与指标：23学科基准；Table 2地球科学任务的IID与跨数据集OOD平均RMSE由冻结agent的1.0963 K降至Linked Full的0.9650 K。 任务原生误差、独立迁移、遗忘、约束保持与更新成本；不可把不同学科量纲合成硬件成功率。
局限：自动评测可能漏掉领域错误；更广泛部署仍需重复运行与分学科区间，未验证GUI或硬件接入成本。
项目借鉴／反证：借鉴“保存证据→可执行修正→独立验证”链，考核跨软件修复是否保留科学约束。 先读：§4重放／验证 → Table 2与§6 → §8局限。

## 2. A self-learning scientific agent for X-ray diffraction

2026-10-06｜arXiv预印本 v1；正文冠名Gan Jiang｜近7天补读｜Bin Cao等；港科大广州／UCL／长三角AI Lab／中科院自动化所。
[原始页面](https://arxiv.org/abs/2610.07862)；[正文／原文1](https://arxiv.org/html/2610.07862v1)。

问题与方法：跨FullProf、GSAS-II、PyWPEM保持同一结构问题与原始衍射证据；诊断失败、修改技能并在冻结版本的留出样本上验证。
应用与控制：专用分析引擎／程序接口，另有delta-cli；artifact ID、SHA-256及分离的观测／模型输入用于交接，未展示通用GUI。
硬件／数据与反馈：模拟图谱与真实来源的既有实验图谱；电池operando序列分析未证明agent在线控制电池或发起新测量。 已接受结构初始化下一张图谱精修；残差与物理约束改变分析及技能，未闭合仪器测量环。
已核结果与指标：无成分输入的opXRD单相top-1为40.83%，最强对照26.45%；这是物相识别准确率。 物相top-1／多相F1、Rwp及参数物理合理性；计算完成不等于科学结论成立。
局限：高度专用工具生态；未量化跨新学科接入人时，也未做GUI/API等预算比较。
项目借鉴／反证：最接近跨软件证据连续性的分析近邻之一；借鉴不可覆盖原始测量、产物校验及科学验收与执行成功分离。 先读：Fig.3／技能学习 → Supplementary Note 2.1的artifact交接与验收。

## 3. Operating advanced scientific instruments with AI agents that learn on the job

2026-03-06｜npj Computational Materials正式论文｜旧文补读｜Aikaterini Vriza、Michael H. Prince、Tao Zhou、Henry Chan、Mathew J. Cherukara；Argonne／APS团队。
[原始正文](https://www.nature.com/articles/s41524-026-02005-0)。

问题与方法：代码编写、审查和图像解释agent将用户目标接到仪器；借专家模板和可检索的用户指令记忆学习流程。
应用与控制：APS HXN远程束线；EPICS／PyEpics与预定义Python函数，另有材料机器人案例；专用集成。
硬件／数据与反馈：真实硬件与新采集的荧光／衍射扫描，非单纯模拟或预录基准。 粗扫后跨模态挑选明亮且孤立的颗粒，坐标用于后续精扫；人类定义目标并提供指导。
已核结果与指标：Fig.2任务要求1 μm定位；作者报告O3在测试模型中能稳定进行跨模态坐标推理，不能外推普遍1 μm精度。 坐标正确性、跨模态区域选择及操作任务可靠性；未给发现收益或通用接入劳动优势。
局限：依赖专家扫描启发与现成控制函数，人机条件影响结果；没有GUI/API等预算对照。
项目借鉴／反证：跟踪APS已关注作者的早期仪器工作；真实“观测→下一动作”已有近邻，贡献需落到新软件接入和长程约束保持。 先读：Results／X-ray nanoprobe experiment → Fig.2、Fig.3及Supplementary 1.1。

## 4. An agentic artificially intelligent X-ray scientist

2026-07-01｜Nature Machine Intelligence正式论文｜旧文补读｜Zhantao Chen、Alexander N. Petsch等；Stanford／SLAC等。
[原始正文](https://www.nature.com/articles/s42256-026-01261-5)。

问题与方法：先在虚拟六圆衍射仪准备提示，再以MCP读日志、图像和扫描结果，寻找参考峰并计算样品取向。
应用与控制：SSRL BL17-2、控制终端、图像及分析工具／MCP；真实实验由人转发模型生成的命令并提示继续。
硬件／数据与反馈：模拟评测与真实Co3Sn2S2／Si测量分开；真实扫描不是预录回放。 识别η约1.22°实测偏移，修正当前电机并把偏移用于第二参考峰的目标角；直接的实测反馈。
已核结果与指标：Fig.3–4及Extended Data Fig.2记录偏移修正与后续找峰；真实试验因束线时间限制未按相同条件系统重复。 真实参考峰定位与取向验证；虚拟基准另测取向角误差和晶格常数误差，不能移作真实成功率。
局限：单类对准任务、专用MCP与提示，人类安全转发；不能称完全无人或统计确立的异常适应能力。
项目借鉴／反证：权威机构闭环反证；可用“同一实测修正有没有进入下一动作”作证据连续性检查，并单列人类介入。 先读：Deploying on a real synchrotron → Fig.3–4、Extended Data Fig.2 → Methods/MCP。

## 5. Astra: an open-source fully autonomous robotic observatory control software

2026-07-14｜arXiv v1；SPIE会议稿｜旧文补读｜Peter P. Pedersen等；ETH／Cambridge／Liège／Bern等。
[原始页面](https://arxiv.org/abs/2607.12898)；[正文／原文1](https://arxiv.org/html/2607.12898v1)。

问题与方法：以ASCOM Alpaca和统一遥测控制无人观测，浏览器界面与程序端共享FastAPI REST／WebSocket后端。
应用与控制：六台真实望远镜、三处设施；Python／Alpaca／API和Web界面，非LLM GUI agent。
硬件／数据与反馈：真实天文观测；不是模拟或预录任务。 指向、导星、焦点等实测反馈调整控制；论文未证明依据新科学发现自主重排研究目标。
已核结果与指标：2026年1／5月数据的网络中位指向散布0.11 arcsec；作者称未发生归因Astra的调度中止，不等于设施从未中断。 指向散布、解算失败和无人值守可靠性；未提供agent科学决策收益。
局限：需站点定制，Windows旧ASCOM COM还需ASCOMRemote包装；接入人时和运行成本未知。
项目借鉴／反证：天文标准API是必须纳入的强基线；GUI优势应由新站适配劳动和科学质量比较来证明。 先读：§3.7站点定制／§4设备兼容 → §5真实观测结果。
