## 1. Principles and Techniques for Agentic Research in Experimental Physics

[原始论文](https://arxiv.org/abs/2610.17193) · [相关正文](https://arxiv.org/html/2610.17193v1)

**作者 / 团队：** 马里兰大学Walsworth团队；Niko R. Reed等；

**首发 / 核验版本：** 2026-10-12 · v1；核验于 2026-10-15。

PhysKit 将 Codex / Claude Code 通过文件交换桥接到已有确定性控制程序，冻结安全限制与评价器。六个案例执行设置不同，不能全部算作硬件实验。NV-NMR 案例中，新测量反馈实际影响后续读出延迟、脉冲与回波间隔的选择及漂移诊断。

**作者证据与限制：** 作者报告20.8小时、151次实验，其中34次正式评分；首次评分用时3.2小时。最佳10分钟0.97Hz，相同设置10次中位1.47Hz，25/34次漂移受限；独立审计否定了所声称的重复纪录。仪器、样品、八步协议和安全范围由人设定，人工耗时参照非配对试验，未提供跨仪器接入人时或公平 GUI 对照。

**建议先读：** §III.4、§IV.5和图6

## 2. Delegating Earth science model calibration to knowledge-guided LLM agents

[原始论文](https://arxiv.org/abs/2610.18378) · [相关正文](https://arxiv.org/pdf/2610.18378)

**作者 / 团队：** 河海大学、南京水利科学研究院、Meta；Zhanliang Zhu等；

**首发 / 核验版本：** 2026-10-13 · v1；核验于 2026-10-15。

知识引导的地球科学校准将单位、参数、观测映射、目标、预算及保留数据写为机器可读契约，先验证运行程序，再冻结方案交给 DDS 等优化器。水文与积雪测试使用历史真实观测和数值模型，没有调度新的现场测量。

**作者证据与限制：** FSM2 首次可执行为有知识5/5、仅模型名0/5，验证NSE为0.81–0.94对默认0.57。VIC 的10组配对、各150次评估下差值中位约−0.003，95%区间−0.007至0.002，非劣界−0.02；结论限于指定预算与目标。10个中断代理臂按规则排除，11次单向量回放不是完整搜索重放，多变量选择部分使用验证信息。

**建议先读：** §2.2、§2.6、§3.4及图5

## 3. Google Earth AI Geospatial Reasoning Agent: Capabilities and a Systematic Evaluation

[原始论文](https://arxiv.org/abs/2610.15750) · [相关正文](https://arxiv.org/html/2610.15750v1)

**作者 / 团队：** Google Earth AI；Noam Slonim等；

**首发 / 核验版本：** 2026-10-11 · v1；核验于 2026-10-15。

Google Earth AI Geospatial Reasoning Agent 通过领域 Skills、Earth Engine、Maps、Data Commons、Python 及外部数据引用来分析已有地理观测。结果可改变后续分析与替代数据选择，但不构成新卫星观测或现场物理再测闭环。

**作者证据与限制：** 76个开放问题、每配置3次运行；Flash 基础3.3、领域52.2、完整62.7，Pro领域50.8加计划47.6。分数衡量流程价值对齐，不是科学正确率。专家参考流程及69条轨迹的207次标注支持裁判核查；基础 Python 不联网、工具能力不等、不可解任务过滤和仅Gemini测试限制比较。

**建议先读：** §3、表4和§6局限

## 4. Stateless Language Agents: Scaling Long-Horizon Automated Research

[原始论文](https://arxiv.org/abs/2610.07625) · [相关正文](https://arxiv.org/html/2610.07625v1)

**作者 / 团队：** Stanford、CMU、华盛顿大学、SambaNova、Berkeley；Qizheng Zhang等；

**首发 / 核验版本：** 2026-10-06 · v1；核验于 2026-10-15。

Stateless Language Agents 用外部执行框架保留候选、证据与预算，由 Advisor 分配尝试，隔离 Worker 用新会话工作。独立且受保护的代码评价器检查候选，检查点支持继续探索；研究任务是内核、算法及软件计算，没有新仪器测量。

**作者证据与限制：** 内核 Codex 每方法3次运行，SLA 的3次均优于三组基线合计9次；达到共同目标用67.9M对986.3M token，93.1%是推理预算减少而非墙钟提速。共享检查点消融及短预算下排序变化提示预算依赖；自动固定评价器的结果不能直接推广到物理漂移和科学目标修订。

**建议先读：** §3、§4.3及附录D.3

## 5. PEAR: A Robust and Flexible Automation Framework for Ptychography Enabled by Multiple Large Language Model Agents

[原始论文](https://arxiv.org/abs/2410.09034) · [相关正文](https://arxiv.org/html/2410.09034v1)

**作者 / 团队：** Argonne国家实验室、Rice大学；Xiangyu Yin、Chuqiao Shi、Yimo Han、Yi Jiang；

**首发 / 核验版本：** 2024-10-11 · v1；核验于 2026-10-15。

PEAR 将领域知识、询问、参数核查和用户确认组织为多个语言模型智能体，操作 Matlab 相干衍射重构流程，而非显微镜 GUI 控制。测试使用已有 SnSe 衍射数据，并把成功运行、运行但结果错误、语法错误等结果分开。

**作者证据与限制：** 2024年论文的100种假设情形用GPT-4模拟用户，与专家参考比较，不是100次无人值守新物理实验。人工 Level 1 图像反馈能改变下一步参数。贝叶斯优化对比来自前作，非同预算对照；没有独立复现，不能从重构流程推断远程设备开放资格、费用或时延。

**建议先读：** §2.3、图2、§3及附录B
