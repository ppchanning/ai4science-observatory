# 科学软件与证据恢复｜2026-10-22

AI辅助资料整理；本期5项首次进入本集合，保留来源原始日期，不表示当日新发表。推荐不代表维护者已读；数字为作者报告，未独立复现实验。真实执行、训练环境改造、工具仿真和工程经验分别说明。

## 1. CUA-Recovery: Benchmarking Error Recovery in Long-Horizon Computer-Use Agents

Xu Hu等；UT Dallas、Manchester、Rice、UT Austin、UC Davis等。arXiv预印本，来源首发日期：2026-10-20；版本：v1。[原始来源](https://arxiv.org/abs/2610.27645) · [正文](https://arxiv.org/html/2610.27645v1)

数字桌面发生错误后，代理既要发现偏离目标，也要真正修好。CUA-Recovery用ReRail组合MyPCBench任务，保留持续的GUI与CLI状态，并在策略自然失败后让恢复代理接手。可执行验收器确认失败及最终结果，错误意识另由模型判分；两种指标不能互换。

测试包含100项任务、2,250个错误状态；训练集含377项任务、8,577条验证过的恢复轨迹。任务平均约60步，67.5%涉及多应用。人工分析619次失败，规划与感知错误占57.3%。六种代理与六种接手深度中，最高错误意识率44%、最高Pass@3为25.5%，这两个最高值来自不同配置，后者也不是单次成功率。

Qwen3.5-35B-A3B经过恢复训练，错误意识率从19.9%到35.2%；相同token预算的成功轨迹训练为23.6%。删除旧截图可能改善察觉却损害修复，但不同接手深度的失败集合不同，不能据此作单一因果解释。

**证据限制：**错误意识含模型判分；不同深度失败样本不同；数字桌面结果未验证科学仪器。

**建议先读：**§3–4及恢复训练对照

## 2. Lost in Recovery: Demystifying Recovery Behavior of Computer-Use Agents via Goal-Oriented Action Replay

Byeonghun Bang、Sangwoo Park等；KAIST、ETRI、DeepAuto.ai。arXiv预印本，来源首发日期：2026-10-20；版本：v1。[原始来源](https://arxiv.org/abs/2610.27954) · [正文](https://arxiv.org/html/2610.27954v1)

恢复到一张相似截图，是否就能继续完成原任务？ReTrace以“恢复后还能承接原轨迹”为判据：回放原成功轨迹的后续动作，再运行原任务验收器。它把外观相似和任务状态可继续区分开。

作者从OSWorld与WindowsAgentArena中筛选连续三次回放都成功的轨迹，再注入受控扰动，让代理利用目标和历史执行键鼠恢复。这提供了可重复的数字环境控制，却也筛掉了本来不稳定的任务，不能模拟物理实验中不可逆的样品消耗。

Qwen3.5-9B在OSWorld三次运行中的成绩由39.38±1.17%到44.26±1.90%，提高4.88个百分点。实验前向预算50步，另给每次恢复10步及检测调用，因此不是等总预算比较。代理或Google Drive配置相关任务被排除，最终分母未获充分核实，不据此反推成功题数。

**证据限制：**稳定回放筛选限制代表性；恢复和检测另耗预算；无物理可逆性验证。

**建议先读：**§5.1–5.2、表2、附录B.2

## 3. CUA-Lite: An Open Platform for Computer Use Agents

Zhanhui Zhou、Weichen Zhang等；Dawn Song参与，Berkeley联系邮箱。arXiv预印本，来源首发日期：2026-10-19；版本：v1。[原始来源](https://arxiv.org/abs/2610.26071) · [正文](https://arxiv.org/html/2610.26071v1)

电脑操作研究常为每个基准重做环境适配、截图和动作记录。CUA-Lite以Lite.Gym统一reset/step接口，Lite.Sample保存共同轨迹格式，再保留模型专属封装，支持评测、监督微调与强化学习复用。它连接12个基准，核心桌面实现采用容器而非虚拟机。

作者在共同可运行的332项OSWorld任务上比较13种模型：原369项减去29项不可用和8项Google相关任务。相对原实现，平均绝对分差2.7个百分点，最大5个百分点，Spearman相关0.98。较高排名相关性不表示每个任务行为或分数完全相同。

报告内存占用约为原来的六分之一，启动时间约为四分之三；这些是特定环境的资源指标，不是科研接入工时或仪器排队成本。本文采用v1口径，动态[作者项目页](https://cua-lite.github.io/)可能有不同计数。统一数字轨迹也不等于已经构成科学测量反馈闭环。

**证据限制：**共同可运行任务子集；资源节省不等于科研集成成本；未进行科学任务等预算接口对照。

**建议先读：**§2.1–2.3与附录D

## 4. The Scheduler Is a Hidden Retriever: How Asynchrony Shapes Evidence Acquisition in Search Agents

Ruiyang Ren、Yuhao Wang、Yinan Zhang、Chunyan Miao；NTU。arXiv预印本，来源首发日期：2026-10-19；版本：v1。[原始来源](https://arxiv.org/abs/2610.26310) · [正文](https://arxiv.org/html/2610.26310v1)

异步搜索中，先返回哪条证据可能改变代理下一次搜什么。本文以固定结果的到达顺序回放，与同条件重复运行噪声比较，研究调度怎样改变证据获取路径，而不只是最终回答的排列。

实验覆盖两个模型系列及2Wiki、HotpotQA、MuSiQue三个多跳问答基准。证据获取分歧在部分配置中比重复运行高出最多24个百分点。CEA预先固定子问题及依赖，仅在所需证据齐备后释放后续工作，并以确定性规则分配共享预算，避免先就绪任务先耗尽额度。

CEA使获取分歧落到重复运行约1个百分点以内，准确率在部分配置最高提高12.6个百分点。这依赖固定计划与稳定响应；等待更完整证据并不保证所有预算下都更准确。结果来自文本问答，尚无GUI操作或科学仪器验证。

**证据限制：**固定计划及稳定响应假设；最高增益依配置而异；未验证仪器环境。

**建议先读：**引言、§3.2、§4–5

## 5. LatticeMind: A Validation-Gated Agentic Framework for Density Functional Theory Workflows

Nathaniel M. Vegh等；Nanoacademic、McGill。arXiv预印本，来源首发日期：2026-07-19；版本：v1。[原始来源](https://arxiv.org/abs/2610.26869) · [正文](https://arxiv.org/html/2610.26869v1)

LatticeMind把自然语言DFT需求转换为工作流契约，明确阶段、产物和依赖，再用确定性规则检查输入文件，允许有界修复，通过后才授权执行。对象是RESCU/VASP数值计算，反馈来自计算与文件验收，不是物理仪器新测量。

冻结的44个RESCU案例与3种后端共132次运行中，119次首个计划通过，13次经一次修复通过，均达到参考验收。23案例子集、每项三次重复的消融中，常规反应式修复约71%，完整框架100%。这些成绩依赖专用规则、文档及配置，迁移求解器仍需工程工作。

VASP的19项案例均通过科学验收；直接一次生成基线仅7/19可运行，后者判据更宽，不能作为同口径成功率相减。日期也有未解决冲突：来源元数据写2026-07-19，封面为7月14日，而arXiv编号以2610开头；保留该冲突，不把它称为十月新发表成果。

**证据限制：**冻结案例与专用校验规则；VASP基线验收口径不同；日期元数据冲突未解决。

**建议先读：**契约/校验、消融与VASP迁移段
