# 科学代理与实验阅读笔记｜2026-10-13

从铁电薄膜与薄膜合成的测量反证，到量子实验代码工具、计算研究预测和天文数据语义。区分真实物理测量、计算评价与已有观测产品分析。

共5篇公开来源资料。AI辅助整理；推荐不代表维护者已读，作者报告未独立复现。所述核查范围来自上游资料，未核全部代码与补充数据；旧文新入库不等于新发表。

## 1. Human-agent discovery of reconfigurable in-plane ferroelectric superdomain control

来源：[原始页面](https://arxiv.org/abs/2609.06887) · [全文入口](https://arxiv.org/pdf/2609.06887)；UTK、Rice、UC Berkeley；Yu Liu、Sergei V. Kalinin等；首发 2026-09-07，核查版本 v1。

这篇论文研究怎样用扫描探针改变铁电薄膜中条纹状超畴的方向。困难不只是寻找最佳电压：研究开始时，应该用什么量描述图像、什么操作真正能改变方向，以及一次“没有变化”究竟意味着材料不响应还是仪器没执行，都尚未明确。常规优化通常要求这些事先固定。作者的 SPARC 则让编码代理与研究者在同一显微镜、同一实验笔记中逐步建立这些定义，再用新实验修订它们。

代理先重分析过去的人工作业图像，从图像的二维傅里叶变换提取三个方向的相对权重，并配准前后图像，比较同一位置，而不是拿不同区域的平均图像推断变化。随后它提出带预期结果、未处理区域对照和操作条件的写入方案。第一阶段所有写入都由人执行，研究者不断纠正测量、解释和物理逻辑；第二阶段 Claude Opus 4.1 在 Claude Code 中通过 Python 包装器及 AESPM 仪器接口下发操作、读取新图像，研究者仍在现场并保留停止权。这是文件、代码与专用仪器接口协作，原文没有展示截图 GUI 操作或远程开放设施访问。

科学连续性由两份记录承担：FINDINGS.md 保存结论、证据、不确定性和适用条件，旧结论被反驳后标为撤销或替代；PITFALLS.md 保存分析和硬件故障。后者部分被转成可执行检查。例如轨迹执行完但电压未到探针时，加入阳性对照可以阻止代理把硬件故障解释为电压太低，继而继续加压。另一个关键例子是，旧记录认为某种扫描会减少沿扫描方向的超畴；在未处理薄膜上，新测量却显示该方向比例从0.415升至0.601。排查探针、共振、图像分析并确认同框对照后，代理把规律修订为依赖样品准备状态，并用它准备后续图案的背景。

实验证据还检验了控制规律。交替正负极性的点阵能选择方向；匹配电暴露的同极性点阵没有超过基线的变化，原先认为必须精确匹配条纹周期的规则也被新测量否定。这里的暴露指电压乘时间，作者没有测电流，不能改写成等电荷对照。第二阶段记录9个代理发起的闭环周期及8次自行停止，但停止多是检查发现无效条件，不能把9减8算成科学成功率。两阶段的任务、已有知识和人员参与不同，也不能用总仪器时间直接宣称提速。

证据限制：单仪器、单薄膜，人工共建表示和检查；无GUI/API公平比较、无迁移人时

阅读建议：§3.2—3.3、图2、§8.3—8.4；结合方法、结果及限制阅读。

## 2. Hypothesis-Driven Autonomous Materials Synthesis with Multimodal LLM Agents

来源：[原始页面](https://arxiv.org/abs/2609.18598) · [全文入口](https://arxiv.org/html/2609.18598v1)；University of Tokyo、Rigaku；Takahara、Hitosugi、Mizoguchi等；首发 2026-09-16，核查版本 v1。

自动合成实验通常把测量压成一个分数，再让优化器寻找高分条件。SynAgent 想保留更有科学意义的输出：哪些条件会成功，为什么这样预测，什么新结果足以改变理解。作者选择钴酸锂薄膜沉积，研究基底温度与结晶情况的关系。其他制备条件固定，所以这是一维条件探索，不是同时自主安排多种材料、设备和科学目标。

系统从人配置的实验范围、目标和预算开始。主代理读取已执行条件、X射线衍射数据、扫描电镜图像以及可修订的文字理解，提出下一个温度和定量预测。专用自动实验平台 dLab 制备真实薄膜，衍射仪和电镜取得本轮新数据，再通过 MaiML 格式关联文件与图像交给代理。分析技能不是开局预写的：第一轮生成提取衍射峰比和电镜亮颗粒比例的代码，附自测与技能说明，随后18轮都复用这两项；衍射目标保持固定，以免分析工具变化悄悄改变评判标准。这里靠平台集成与生成代码，没有证据表明代理跨仪器软件点击 GUI。

每轮分别采用验证或反驳模式，二者按预设次序交替。验证尝试当前理解认为会成功的条件；反驳尝试其认为会失败的条件，检验解释是否过窄。第10轮尤其清楚：代理认为650°C仍低于结晶阈值，预测两个指定衍射峰的强度比约0.2；实际测到54.9，反而是当时最好结果。它因此推翻“阈值靠近700°C”的解释，转向较低温区继续测量，最终将转变夹在630—650°C，较好生长窗口定位为650—690°C，670°C的峰比61.6为本轮最高。峰比是论文使用的结晶排序代理指标，不是61.6%的成功率，也不能单凭它判断化学成分。

18次均是新制备和新表征，而不是在历史数据上模拟选择。电镜又帮助区分衍射表现相近的薄膜形貌，但亮颗粒究竟是第二相、成分分离还是另一种结构，原文没有由电镜证明。实验展示了反驳预测如何改变温度选择和最终文字理解，却没有等测量预算下重新运行贝叶斯优化的实物对照。每个温度只访问一次，最优区内的小差异可能来自波动；作者称生成指标与同数据人工分析一致，但这仍不同于独立验收整套科学解释；技能自测和代理对预测的支持/反驳判断也不是独立科学验收，后者没有统一数值容差。

证据限制：无等预算实物BO对照；技能自测、LLM判断无统一数值容差；基础设施已集成

阅读建议：图3逐轮理解变化、Methods；结合方法、结果及限制阅读。

## 3. JANUS: Enhancing Long-Horizon Autonomous Research with Co-Evolving World Models

来源：[原始页面](https://arxiv.org/abs/2610.13194) · [全文入口](https://arxiv.org/html/2610.13194v1)；ICT CAS、UCAS；Mengdi Liu、Chenghao Jia、Hong Chang等；首发 2026-10-09，核查版本 v1。

JANUS 处理的是计算研究中的反馈延迟：代理不断改代码、训练或测试，每次真正执行都花时间；如果只等执行完再反思，有限预算可能被大量不值得运行的方案耗尽。作者在提出方案与执行之间加了一层预测。论文称它为“世界模型”，这里主要指利用研究状态和过往结果推断候选方案价值的模型，不是已校准的仪器数字孪生。

代理接收任务目标、代码环境、历史实验和剩余预算，在演化图中提出多条改进路线。预测层比较它们可能提高多少目标表现、获得什么新信息以及打开哪些后续路线，通过候选间比较来排序、修订或剪枝。选中的方案才交给代码执行器实现并评估。真实运行产生的分数和失败信息返回系统，再分别整理成生成方案的技能、预测与探索策略，以及两者协作规则。这样既有过去经验，也有对下一次运行的明确预判；预测仍要由执行结果纠正，不能把高预测分当作已得到科研结果。

主要对照是 MLS-Bench-Lite 的30项研究任务，覆盖12个领域，每项要求改进机器学习系统的一个组件并在控制条件下验证。各方法每次运行分配一张 A100、每题5小时墙钟预算，初始设置、目标与评估协议相同，并允许查看文件、修改许可范围内代码和反复实验。使用同一 DeepSeek-V4 Flash 主干时，JANUS 的30项提交全部通过有效性检查，13项超过该题给定的所有人工基线，表中对应43.3%；Codex对应11项，即36.7%。这是与任务预设人工基线的比较，不是与临场研究者竞赛，也不代表每个科学问题都得到新发现。

同主干下，平均归一化测试分为41.07，对照 Codex为38.91；这是跨任务汇总的评分，不是41.07%的成功率。换更强主干或结合 Codex 框架还能提高成绩，但不能拿不同主干行的差异全部归因于预测层。论文另展示语言模型训练和注意力算子优化的持续进展。所有这些反馈来自代码运行及计算评估；作者把昂贵执行称为“physical execution”的段落也不能据此解释为连接了真实物理仪器。

证据限制：计算领域，不迁移硬件结论；主干不同不可混比；预测不等于测量

阅读建议：图2、§4.1、表1；结合方法、结果及限制阅读。

## 4. Large Language Model-Assisted Superconducting Qubit Experiments

来源：[原始页面](https://arxiv.org/abs/2603.08801) · [全文入口](https://arxiv.org/html/2603.08801v1)；University of Chicago为主；Shiheng Li、Andrew N. Cleland等；首发 2026-03-09，核查版本 v1。

超导量子实验中，一段看似简短的测量要求往往要转成脉冲序列、仪器通信、数据保存和拟合。HAL 的目标是让语言模型在已有实验知识的支持下，现场生成能执行的工具，而不是让研究者为每一种完整实验提前定义固定工具。作者用真实低温超导器件展示谐振器表征和从文献迁移来的量子非破坏性读出表征；后者用于判断读出会怎样改变被测量子的状态。

人的实验请求先到规划代理。它检索知识库中的硬件 API、协议和代码，开发代理据此写 Python，并在实验环境中执行。仪器通过局域网连接，已有控制层包含 QICK/RFSoC 脉冲平台、矢量网络分析仪和电压源；数据存到共享服务器，Grapher 提供实时图形显示。代理的控制依据是生成代码和返回的数据、文本及数值，原文没有让它用 Grapher 截图点击。跨轮状态通过运行时 STATE 字典及代码复用保存；长期知识库中的成功代码由人审查后纳入，所以“无固定工具模式”仍依赖既有驱动、知识和人工维护。

谐振器例子有意设置了一个不完整请求：人说有8个谐振器，却只给覆盖4个的频率范围。代理先真实扫描并识别出4个，这时并非自行扩大全部探索范围，而是人在第三周期明确扩展范围；代理重新扫描找到8个，再细扫并拟合各自的内外耦合品质因子。五个周期中第二、第四和第五周期不需额外用户指令。这个过程有测量反馈和代理后续动作，但关键搜索范围变化由人发起，应与完全自主诊断并拓展搜索区间区别。

作者报告准备好提示后该流程约5分钟，包含网络分析仪扫描，不包括低温系统准备、排队或初次接口适配。它是一条案例时间，没有多次重复的人工作业对照。在文献复现案例中，通用实验说明先被转成适合本实验室硬件的流程，再生成脉冲控制和拟合，测得泄漏参数0.124±0.017；该量描述量子态离开计算子空间的程度，不能读成代理错误率。论文由这两例证明按需代码工具能实施真实测量，并没有用它们证明任意量子实验可自主复现。

证据限制：两案例无重复比较；驱动知识库已建；无新硬件适配人时

阅读建议：五周期谐振器案例、知识库部分；结合方法、结果及限制阅读。

## 5. radio-astro-tools: linking radio astronomical data to the astronomical Python ecosystem

来源：[原始页面](https://arxiv.org/abs/2610.11429) · [全文入口](https://arxiv.org/html/2610.11429v1)；NRC Canada、UF、NRAO等；Eric W. Koch、Adam Ginsburg等；首发 2026-10-08，核查版本 v1。

射电天文的数据分析常从 CASA 开始，但科学问题可能还需要其他波段的数据、区域标记、统计分析和可视化。困难不仅是找到某个菜单：不同工具必须一致地理解天空坐标、频谱轴、亮度单位以及仪器的成像分辨率。CASA 的部分计算在底层 C++ 中完成，按任务串接往往要落盘中间产物；其软件环境也曾增加社区 Python 包接入困难。作者介绍 radio-astro-tools 如何把这些射电数据带入 Astropy 及科学 Python 的共同数据生态，同时指出模块化 CASA 已改善安装与互操作，并非宣称 CASA 无法使用外部包。

输入通常是已有观测经成像后的三维数据立方：两个天空方向加一个频谱方向，每个像素都有光谱。spectral-cube 读写这些数据，保留坐标和单位，支持掩膜、切片、积分等操作，并用延迟计算避免一次把大数据全载入内存。casa-formats-io 读取 CASA 表与图像；radio-beam 处理决定图像分辨率的波束，让不同通道可卷积到共同分辨率，再比较亮度；uvcombine 合并单天线和干涉阵列对不同尺度结构的响应。研究者通过 Python 和浏览器中的 Jupyter 教程调用它们，交互画出的天空区域也可保存并回用于 CASA 的清理掩膜。这是人指导的数据分析流程，没有自主代理，也没有本轮新指向或新曝光。

这样做的科学意义是，证据跨软件时仍保持同一坐标、区域和分辨率。两个图像数值看似接近，若波束不同，实际并非测量同样尺度的结构；区域若只以屏幕像素记录，也难以复用到另一张图。论文提供坐标重投影、用一幅数据的掩膜分析另一幅、提取位置—速度图等具体教程，展示这些语义如何随数据移动。这些是可运行的软件能力说明，不是自动发现效率的性能基准。

附录B给出了一个边界清楚的数值核对：作者生成已知幂律结构的模拟图像，用15角秒高斯波束模拟单天线，用2—40角秒尺度的理想滤波模拟干涉响应，将相同输入、相同缩放因子和滤波设置分别交给 uvcombine 与 CASA 的 feather 合并算法。所得图像视觉一致，主要偏差在微弱结构，拟合幂律指数差异在一倍标准差以内。它支持该操作在所测模拟条件下数值相容，不证明在所有真实射电数据中等价，更不是新观测反馈闭环或跨软件速度胜出。

证据限制：特定模拟数值相容非全部真实数据等价；无速度或接入人时对照

阅读建议：§1.1、§5.2、附录B图5；结合方法、结果及限制阅读。
