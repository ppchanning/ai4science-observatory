# Scientific Computer Use · 2026-09-28

AI 辅助整理的公开资料阅读笔记。数字与结论归属于所引作者；未独立复现实验，也不代表维护者已逐篇阅读。历史核验信息见书目。

## 1. 优先读：FermiLink 的真实实验闭环

**Autonomous Quantum Transport Measurements of 2D Semiconductors by an AI Agent** — Brandon Bauer 等；2026-09-22，arXiv v1预印本，**本期新作**。[原始摘要](https://arxiv.org/abs/2609.26661) · [原始PDF](https://arxiv.org/pdf/2609.26661)

- **问题与方法：** FermiLink 轮换测量与分析 agent，共享科学记忆与文件；等待由 harness 轮询，硬件通过冻结的 Python 采集脚本操作。涉及 Codex、采集/分析代码和低温输运仪器；不是通用截图GUI。
- **已核结果与反馈：** 作者报告真实 MoS₂ 器件连续实验最长六天。新结果决定后续扫描范围；低质量器件无可靠 FFT 峰时提前停止。科学产物包括约13 meV的自旋轨道耦合能（依赖给定有效质量）及层/能谷相图。
- **边界：** 专家先以已有数据 dry run 调试领域 Skills，之后才是真实测量；自主性发生在专家定义的工作流内。未证明跨软件通用迁移、公开远程资格或低接入成本。

## 2. OSWorld-Pro：把“证据连续性”拆成可审计的过程

**OSWorld-Pro: Process-based Evaluation for Computer Use Agents** — Zhilin Wang 等，NVIDIA；2026-09-21，arXiv v1预印本，**本期新作**。[原文](https://arxiv.org/html/2609.24890v1) · [版本记录](https://arxiv.org/abs/2609.24890)

- **问题与方法：** 为跨应用任务标记依赖子目标的可行性、推进和完成，再构建与人工对齐的过程评判。覆盖 LibreOffice、VS Code、终端等Linux应用，评价GUI操作轨迹。
- **已核结果：** 305任务、2814子目标、67264人工标签，平均3.45应用和9.2依赖子目标。作者报告最强模型75.7%，OSWorld参考83.4%；不同基准分数不能作单因素因果解释。
- **硬件/反馈/指标：** 真实桌面软件，无物理仪器或新测量反馈；指标是操作过程与完成度，并非科学结论正确率。LLM评判不能替代数据与不确定度核验。

## 3. CADWorld：科学产物必须经得起检查

**CADWorld: Computer-Use Benchmark for Long-Horizon Computer-Aided Design** — Zihan Dong 等，Georgia Tech等；首发2026-09-14，所核v2为09-21；arXiv预印本，**近30天补读**。未核版本差异，不把v2算全新论文。[原文](https://arxiv.org/html/2609.16251v2) · [版本记录](https://arxiv.org/abs/2609.16251)

- **问题与方法：** 用截图GUI操纵FreeCAD，以原生可编辑文件中的几何、尺寸、约束、模型历史及CAM/FEM状态验证任务。
- **已核结果：** 200任务、11类工作流；7种agent最佳17.5%，专家参考87.0%。这是软件与数字设计/仿真；多个工作台仍是单应用，没有真实机床测量反馈。

## 4. 远程能源实验：专用集成是必须保留的对照

**A Modular IoT-Enabled Remote Laboratory Platform for Hybrid Energy System Research and Engineering Education** — Lamine Chalal 等；arXiv上线2026-09-01，v1，**近30天补读**。PDF有会议排版，本轮未另核正式出版日。[原始摘要](https://arxiv.org/abs/2609.00815) · [论文PDF](https://arxiv.org/pdf/2609.00815)

- **问题与方法：** Web HMI（ViewON）、TIA Portal及MATLAB/Simulink分层接入PLC/VPN实验台，采用OPC UA、PROFINET、Modbus等专用集成。三个入口不等于一个agent跨应用运行。
- **已核结果与硬件：** 包括真实电气装置、能源仿真器及人工光照PV，非纯软件模拟，也非自然户外能源实验。相同条件本地/远程能源、电池、负载能量差异为4.0%、1.4%、2.6%。
- **反馈与局限：** 测量功率/SOC影响固定能量管理模式；没有LLM据新证据重设科学实验。典型单向通信100 ms、观测峰值4 s，均不能当排队或完整实验周期；个人接入与成本未核。

## 唯一平台核验：LabsLand Hive（首次证据基线）

这不是平台本周更新。官方页面与操作文档确认：继电器把真实元件接成电路，点击测量取得物理结果；示波器可导出CSV，因此可保留为电子实验候选。[平台](https://labsland.com/en/labs/electronics-hive/) · [测量流程](https://labsland.com/pub/docs/experiments/hive/user/en/taking_measurements.html) · [官方参考文档§4.1.7、§4.2](https://labsland.com/pub/docs/experiments/hive/hive-node-reference-documentation.pdf)

| 可行性问题 | 本轮证据 |
|---|---|
| 排队／实验／分析耗时 | 文档区分取得结果时间UPRT与含清理的节点处理HPRT，繁忙时另有排队。测试表为**2023年5月**，不作为当前时延承诺；当前三类耗时未知。 |
| 接入工程量 | 有浏览器界面及CSV导出；未核自动化/API使用条件、迁移工时，不能据此声称接入更省。 |
| 运行成本与资格 | 个人资格、费用、额度均未核；没有沿用附件价格。 |
| 闭环边界 | 支持用户改电路再测；未证明自主科研agent闭环或科学结论质量。 |
