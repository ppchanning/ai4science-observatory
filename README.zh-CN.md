**把分散的 AI4Science 进展，整理成能阅读、追溯、比较和继续探索的知识入口。**

AI 正在进入科学研究的多个环节：分析数据、构建模型、提出假设、编写科学代码、操作专业软件，乃至连接真实仪器和远程实验平台。本仓库连接这些环节，帮助读者理解一项进展研究什么、使用什么方法、有什么证据，以及接下来值得读什么。

这里提供持续整理的科学新闻、论文解读、专题书目、公开信源和结构化目录。你可以跟踪每天的变化，也可以沿着一个问题读下去，或下载数据建立自己的文献与产业分析。

## 可安装的 Agent Skill

[查看 Skill](skills/ai4science-research/SKILL.md)：把指南、JSON 证据和原始来源串成可执行的研究流程。示例：为需要保留可追溯引用的文献综述选择科研 Agent。

```sh
npx skills add ppchanning/ai4science-observatory --skill ai4science-research
```

通过 Skills CLI 安装到支持的 Agent；首次运行会获取 CLI。Skill 本身是只读研究流程，输出包含依据、未知项和下一步核验。平台目录的收录状态与安装能力分别核实。

在 [Agent Skill Hub](https://agentskillhub.dev/u/ppchanning/sk/ai4science-research) 和 [askill](https://askill.sh/skills/gh/ppchanning/ai4science-observatory/@ai4science-research) 查找这个 Skill。[DeepWiki](https://deepwiki.com/ppchanning/ai4science-observatory) 提供仓库导览和问答；其生成说明仍需对照引用的源文件核查。

## Explore the landscape

### AI for scientific discovery · AI 与科学发现

从科学问题出发观察 AI 方法：数据与表征、预测与建模、科学计算、实验选择和结果验证。每日新闻与跨学科论文目录提供宽视野，帮助读者把单篇论文放回学科、方法和研究流程中理解。

**阅读入口：** [科学日报](digests/README.md#ai4science-daily) · [核心论文目录](data/catalogs/core-papers.csv) · [综述目录](data/catalogs/surveys.csv)

### Scientific agents · 科研智能体与计算工作流

关注 Agent 如何组织文献、代码、工具与多步骤任务，以及结果如何被记录和检查。阅读重点是系统的实际工作方式、产出物和验证证据，便于比较不同科研工作流。

**阅读入口：** [科研智能体专题](topics/scientific-agents.md) · [科学智能体书目](resources/papers.md)

### Scientific computer use · 科学软件与专业工具操作

关注 Agent 使用图形界面、终端及专业软件完成科学任务：它看到了什么、采取了什么动作、运行结果如何验证、长任务在哪些环节失败。材料包含科学软件使用、计算环境与过程评测相关论文。

**阅读入口：** [科学软件操作专题](topics/computer-use.md) · [晨读归档](digests/README.md#scientific-computer-use)

### Remote experiments · 远程实验与真实科学仪器

把远程科学实验纳入同一条研究链：从工具调用到仪器控制、测量反馈和实验闭环。论文阅读与平台目录一起呈现，帮助读者区分模拟环境、真实设备演示与可访问的公开设施。

**阅读入口：** [远程实验专题](topics/remote-experiments.md) · [平台与公开证据](resources/remote-labs.md)

### Data & evaluation · 数据、验证与研究可信度

关注研究用了什么数据、任务和对照，报告的结果支持什么结论，以及适用范围在哪里。阅读时保留版本、测量对象和未知条件，为比较不同方法提供上下文。

**阅读入口：** [数据与评测专题](topics/data-and-evaluation.md) · [编辑标准](docs/editorial-policy.md)

## Research and industry data

除每日阅读外，仓库提供便于筛选和二次分析的 **UTF-8 JSON / CSV**。字段说明、记录数量和快照日期见 [Data Guide](data/README.md) 与 [数据清单](data/datasets.json)。

| 数据层 | 已提供材料 | 常见用途 |
| --- | --- | --- |
| 研究文献 | 核心论文、综述、被引文献、已纳入论文及候选阅读集 | 建立文献表、筛选研究方向、追踪相关工作；候选与正式纳入分别标注 |
| 科研与产业 | 公司、融资事件、岗位、机构项目、上市公司相关举措 | 观察技术转化、组织布局和历史人才需求 |
| 新闻与书目 | 去重新闻 JSON、科学智能体论文 JSON、关联归档路径 | 本地检索、时间线分析、连接读书笔记与来源 |
| 信息与设施 | 信源 JSON、远程实验平台证据 | 建立持续跟踪清单，查找公开项目和设施入口 |

不同论文表可能重叠，行数不能相加当作独立论文数。产业材料是带日期的公开信息快照，岗位和平台访问条件需要重新核验。

## How to use this repository

1. **日常跟踪：** 从最新日报选一个感兴趣的事件，阅读解释，再打开原始来源。
2. **专题阅读：** 从主题页进入相关书目，结合晨读中的方法、限制和建议章节形成阅读顺序。
3. **建立自己的资料库：** 下载 JSON / CSV，在表格或分析工具中按字段筛选；保留来源与快照日期。
4. **补充与纠错：** 为遗漏论文、元数据修订或证据问题提交 [Issue](https://github.com/ppchanning/ai4science-observatory/issues) 或 Pull Request，按 [贡献指南](CONTRIBUTING.md) 附上原始出处。
