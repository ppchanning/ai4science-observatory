## 1. **EAA: Automating materials characterization with vision language model agents**

2026-02-17｜arXiv预印本 v1｜旧文补读；已关注APS团队的重要先行工作，不是新发表或版本更新。Ming Du、Mathew J. Cherukara等；APS/Argonne。[原始页](https://arxiv.org/abs/2602.15294) · [正文](https://arxiv.org/html/2602.15294v1)

问题与方法：GPT-5视觉推理与确定性任务管理混合；工具内拟合与相位相关校正漂移。应用/控制：APS 2-ID-D XRF束线、Python仪器工具、Web/CLI入口；专用工具、双向MCP；支持既有软件截图输入，不是通用GUI鼠标操作对照。

实物与反馈：真实Cr/Au材料样品的新扫描；无生物方向、非模拟或预录；新扫描FWHM用于下一步细搜；图像定位用于移动和再采集。已核结果：聚焦例扫描8个位置；Siemens star搜索8次采集，末次仍仅近似居中。科学指标：线剖面Gaussian FWHM、位置偏差、扫描数和漂移。

## 2. **Artifact-centered Claim-aware Observability for Autonomous Scientific Agents**

2026-08-18｜arXiv预印本 v1｜旧文补读；已关注APS作者线索的重要先行工作。Xiangyu Yin、Ming Du、Michael H. Prince、Mathew J. Cherukara。[原始页](https://arxiv.org/abs/2608.18312) · [正文](https://arxiv.org/html/2608.18312v1)

问题与方法：为产物、主张、指标、血缘和人工steering定义可追加事件；区分生成关系与科学支持关系。应用/控制：OpenTelemetry、PROV-O、RO-Crate衔接方案；接口无关的审计层；无跨GUI系统实测。

实物与反馈：方法/观点提案；没有真实硬件或模拟benchmark验证；支持追踪证据更新与主张失效，未实测闭环科学收益。已核结果：给出八类核心对象与字段绑定例；§6为toy示例，4.2pp不是实验成绩。科学指标：无已测科学准确率或收益。

## 3. **AIM: Agentic Idea Management for Automated Research**

2026-09-29｜arXiv预印本 v1｜近7天补读；早于本期水位。Google Cloud AI Research、University of Wisconsin–Madison；Hyeong Kyu Choi等。[原始页](https://arxiv.org/abs/2609.38445) · [正文](https://arxiv.org/html/2609.38445v1)

问题与方法：显式保存研究brief、想法池、已核经验与评分；Auditor核对实际代码是否落实想法后再更新经验。应用/控制：AutoLab CPU/GPU任务、代码运行与分析；代码/工具调用；非科学GUI对照。

实物与反馈：10项计算研究任务，无真实物理测量、非预录仪器；执行分数及经审计经验影响后续想法选择。已核结果：作者报告相对ScientistOne系统优化+1.6pp、长程模型/CUDA+4.9pp，最高3.1倍wall-clock加速。科学指标：各任务性能分数、执行数、wall-clock；不是硬件科学质量。

## 4. **A hardware-safety-gated system for LLM-written native ARTIQ control code on a trapped-ion platform**

2026-06-25｜arXiv预印本 v1｜旧文补读；直接跨仪器实物反馈反证。Duanyang Wang、Lu Qi、Yuanheng Xie、Norbert M. Linke、Kenneth R. Brown；UMD QLab等。[原始页](https://arxiv.org/abs/2606.27231) · [正文](https://arxiv.org/html/2606.27231v1)

问题与方法：agent生成ARTIQ代码，经模拟边界检查/人工授权后执行；MCP跨离子阱和AWG，外部Markdown保持经验。应用/控制：ARTIQ、AWG、HDF5/JSON日志、外部记忆文件；MCP/RPC＋原生控制代码，非GUI。

实物与反馈：真实Ca+/CaOH+离子晶体；第二Yb+平台仅接口迁移，没有第二组物理闭环复现；Ramsey测量→拟合磁场谐波→AWG补偿→重测。已核结果：自由运行补偿后T2*=1483±73 μs；人工多次指导目标、拟合与参数化。科学指标：Ramsey相干包络T2*，约1.5ms终点。

## 5. **ASCEND: Personal AI Agents for Autonomous Scientific Computing Across HPC Clusters and GPU Workstations**

问题与方法：本地agent经复用SSH操作远程Slurm，站点skill、作业产物和修复记录支持恢复与复现。应用/控制：Claude Code、NCShare/Slurm、天气预报评估、GRASS GIS/r.avaflow；Codex仅可选运行时未作案例对照；CLI/SSH、站点适配工具与skill；非GUI。

实物与反馈：真实共享计算硬件；天气为发布预测数据，地球物理为模拟，没有新物理实验测量；错误日志/数值差异驱动修复重提交、协议检验和后续优化。已核结果：天气曲线偏差z500 2.1%、t850 2.4%；同编译选项修复后串行与16线程输出一致，-O2并行6.8倍。科学指标：发布曲线偏差、导出输出一致性、运行时间；策略拒绝率不是科学指标。

可选阅读问题：跨软件迁移失败时，主要丢失的是对象/单位、证据与主张绑定，还是下一步实验的决策依据？①②可以帮助拆分这三类失效。
