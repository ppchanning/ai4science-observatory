## 1. Subgoal-aware Memory Graph for GUI Agent

**记忆图如何改变 GUI 动作**

该方法离线建立子目标记忆图，把视觉相似状态和成功、失败边关联起来，再根据当前截图检索经验，指导云端 Android 的 ADB 操作。这是截图驱动的数字单应用执行，没有现场仪器测量；视觉相似也不能自动证明样品、单位或校准状态相同。

固定 Qwen3-VL-8B-Instruct，在经过云端兼容性筛选的 13 个 SPA-Bench 英文单应用 level-3 任务上取 3 次运行均值：无记忆为 34.19%，子目标图为 45.30%，相差 11.11 个百分点；平铺子目标为 30.77%，动作图与任务图为 38.46% 和 36.75%。没有逐任务原始计数或置信区间；构建约需 4 GPU 小时，每步检索约 0.5 秒，小样本结果不能直接推广到科学软件。

## 2. Sage-A1.5: From Long-Horizon Execution to Scientific Exploration with Capability Composition

**科学探索需要外部数值验收**

Sage-A1.5 组合规划、执行与审阅能力，并以 Torch 晶体精修引擎处理既有衍射数据。它不等于新完成了一次物理实验。精修案例中独立数值门槛可以否决模型接受意见，下一轮从最近一次获准状态继续，而不是沿着被拒绝的结果累积。

Sc2Au6 案例使用 7,500 个观测值，8 轮中 6 轮获准，Rwp 从 88.3091% 降至 86.1092%，下降 2.1999 个百分点；第 3、5 轮被拒。较高的残差仍限制结构结论，改善目标值不是准确结构的保证。案例没有给出 GUI 与 API 的受控对照，也不能代表系统所有能力都已得到独立验证。

## 3. GAV: A scientific experimentation environment for PDE agents

**内部实验进步与外部科学检验分开**

GAV 建立 Generator–Agent–Verifier 循环，为 PDE 代理生成问题、运行程序并验收。制造解问题以及历史 PIV、ARTEMIS 数据用于约束生成器；补全场也不全部等于真实测量，不涉及实时控制航天器。同一轮用相同问题比较程序，保留获胜者及实验记录。

六类动力学中，生成分布上的 R1–R6 误差下降为 25.4%–90.1%。但 ARTEMIS 的 Astra 内部误差虽下降 73.4%，独立评测的第 6 轮平均误差却达到第 1 轮的 5.69 倍。最终程序对原始种子程序的比较和 R1–R6 比较不是同一基准。代码能执行、内部验收通过和独立科学有效性应分别报告。

- 首发：2026-10-21；核验版本：v1（2026-10-21）。

## 4. ADAPT for Science: A Multi-Agent System for Self-Evolving Scientific Optimization

**冻结优化程序后再测科学模拟**

ADAPT for Science 在离线阶段进化选择器与优化器程序，测试时冻结程序，在线运行可微引力波探测器模拟器，无需模型在线决策。人仍提供模拟器、目标函数、历史结果和预算。这是模拟优化，不是 GUI 操作或新增物理测量。

8 个留出拓扑各在 H100 上运行 4 小时，平均目标值为 0.204，NAAdam 为 0.452；同一选定起点配固定 Adam 为 0.256，有一个拓扑上完整方法反而更差。目标值降低不能等比例改写为物理灵敏度提高，“±”反映跨拓扑差异，开发成本须另算；历史与初始化选择也贡献了收益，不能全归因于优化器本身。

## 5. LAP: An Agent-to-Instrument Protocol for Autonomous Science

**仪器协议草案与真实部署之间**

LAP 提出基于 JSON-RPC、HTTPS 和 SSE 的 Agent–Instrument 协议，以 InstrumentCard、预约、审批与测量元数据表达仪器能力。复用 MCP/A2A 传输并不会消除设备适配器。设施人员仍负责能力与权限，语言请求先成为提案、再经显式提交，实时控制留在设备侧。

正文主要给出对象、状态机和场景演练；§6.3 把部署列为后续工作，没有实测成功率、费用、延迟或已完成的实验活动。样品、单位、校准和不确定度字段值得核查，但当前接入和价格不能由草案推断。本文首发于 2026-06-02，核验 v1；HTML 封面出现的 8 月日期不构成新版本。
