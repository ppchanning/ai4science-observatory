# Scientific Computer Use · 2026-10-04

AI 辅助整理的公开资料阅读笔记。数字与结论归属于所引作者；未独立复现实验，也不代表维护者已逐篇阅读。历史核验信息见书目。

## 1. **OSWorld-Science: A Benchmark of Computer Use Agents for Learning and Using Scientific Software** — 2026-09-30；近7天补读。Dingyuan Dai 等，清华／UCLA／RIKEN等。[原文](https://arxiv.org/html/2609.39903v1) · [日期与作者](https://arxiv.org/abs/2609.39903)。

将科学软件任务交给12个VLM，以产物和执行评分；天文涉及 DS9、CIAO 与 Chandra 存档数据，控制混合 GUI／CLI，没有实时望远镜新测量。天文3任务共36次运行，14次满分，平均部分得分45.1%；全基准最佳73.7%是平均部分得分，不能写成完整成功率。净计数参考1424.92 counts、满分容差0.5 counts；常见错误涉及曝光归一化、角秒与像素、坐标框架。软件计算反馈到后续步骤，不构成物理闭环；天文任务少且未公平隔离控制方式。

## 2. **Strategies for Deploying AI Agents in Production at Scientific User Facilities** — 2026-09-28；近7天补读；部署经验／观点型预印本。Ming Du 等，Argonne／APS。[原文](https://arxiv.org/html/2609.36362v1) · [日期与作者](https://arxiv.org/abs/2609.36362)。

总结真实束线与加速器上的 MCP、共享记忆、确定性执行策略。GUI与agent可读同一权威后端；不是通用屏幕点击。26-ID案例从先前采集的概览图选择细扫位置并调用采集工具；Osprey控制被限制在既有扫描诊断流程。图像反馈影响动作，但不能把单次定位示例和设想的跨设施调查链说成完整自主科研闭环。涉及聚焦、定位、发射度等科学量，没有同预算成功率、适配人时或成本收益的统一对照。

**借鉴／反证：**已有 MCP／仪器层复用应进入低接入成本基线；把实验意图、设定、反馈与scan ID联结保存。**先读：**§3.2.3、§4.1–4.2，再看§3.1.7／§3.5。

## 3. **A Programmable Optics Cloud Laboratory** — 2026-09-14；近30天补读。Sachin Vaidya 等，MIT。[原文](https://arxiv.org/html/2609.16413v1) · [日期与作者](https://arxiv.org/abs/2609.16413)。

PICO以组件、设定、可测量和状态转换统一浏览器／Python SDK，专用后端控制xArm7、透镜和相机。真实光学测量驱动本地优化，MuJoCo仅用于布局与机器人可行性；三组透镜配置演示光自旋霍尔效应。重复测量RMSD 3.87 μm（1.61像素）；5次端到端运行中15次配置恢复均成功，样本仍小。恢复的是可控设定，可测量必须重采；抽象trace也不包含优化内部全部中间状态。高层实验编排由研究者给定，agent集成及面向外部用户的云部署是未来工作。

**借鉴／反证：**配置版本控制与物理反馈已有直接近邻；证据连续性需同时保留新测量和内部优化来历。GUI／API共享抽象是值得比较的路线。**先读：**§IV-C–E、§V-A/V-C、§VI Fig.4／Table I。

## 4. **Agents Are Systems, Not Models: Rethinking Agentic Evaluation** — 2026-10-01；本期增量。Luis Wiedmann 等。[原文](https://arxiv.org/html/2610.01618v1) · [日期与作者](https://arxiv.org/abs/2610.01618)。

**借鉴／反证：**GUI／API／MCP对照应匹配领域提示、依赖、底座和重试预算；用科学质量与多次运行稳定性评价系统。**先读：**§3.1、Table 2、§4.3。

可选阅读问题：把同一测量替换成支持另一种解释的测量后，agent能否保持对象、单位与来历，并真正改变下一步实验？比较上述材料时，应区分测量反馈、对象与单位的保持，以及证据支持的解释。
